猛人桌面助手v18.28正式版
- 主窗口重新设计：深色界面，四个功能做成卡片并显示各自的快捷键，快捷键状态一目了然；设置、日志和使用提示分区排列。
- 主窗口新增“查看完整使用说明”按钮，在窗口中直接阅读全部使用说明。
- 新增 ChatGPT 账号登录：可用 ChatGPT 会员套餐额度翻译截图，额度用完或出错时自动改用 API 翻译服务。
- 翻译设置里的模型改为下拉选择，列出推荐模型和中文说明（推荐 gpt-6.1-sol），也可手动输入其他模型。
- 修复有道翻译经常提示“识别或翻译失败”的问题：原因是请求经过系统代理时连接被中途掐断。现在有道先直接连接，失败再走代理，连接中断时自动重试，仍失败会提示具体原因。
- 新增日志文件：出错原因写入日志，单个最大 1MB、最多 3 个，超过 14 天自动删除；主窗口可查看占用空间、打开日志文件夹或一键清空。
- 托盘菜单的“桌面提醒”“翻译 API 设置”改名为“桌面工具”“翻译设置”，与主窗口一致。

猛人桌面助手v18.27正式版
- 修复截图翻译在中英混排时“互译”的问题：英文句子里夹着中文词语时，过去可能被整段判成中文而翻成英文；现在按英文翻译成中文，中文部分原样保留，结果全部是中文。
- 原文已经是中文的段落不再送去翻译，图上保持原样；截图里全是中文时会提示不需要翻译。
- 万一翻译服务把某段翻成了英文，自动保留该段原文，不会出现英文译文。
- 修复英文段落中相邻两行长短差别较大时被拆成两段翻译的问题。

猛人桌面助手v18.26正式版
- 改进 F1 截图翻译：识别出的文字先按段落合并再整段翻译，不再把一句话拆成几行分别翻译，修复译文意思错乱的问题。
- 译文排版改为同一级别文字统一字号、每段靠左对齐，修复翻译后文字有大有小、排列不齐的问题；标题仍保持比正文大。
- 能识别列表前面的圆点或“-”“1.”等符号，每一项单独翻译并保留符号；原文是彩色文字时尽量沿用原来的颜色。

猛人软件v18.18版
- “修改快捷键”的全局功能页新增“打开/关闭计算器”和“计算机睡眠”，两项都可自行修改或清空，并与 F1、F2、F3、F4 及教鞭工具快捷键统一进行重复冲突检查。
- 计算器默认快捷键为 Shift+Q：第一次按下打开 Windows 计算器，再按一次关闭计算器，可反复切换。
- 计算机睡眠默认快捷键为 Shift+F12；快捷键按下后直接进入普通睡眠，不弹出二次确认。F3 桌面工具栏中的“睡眠”按钮仍保留确认框。
- 旧版设置会自动补充并保存这两个新快捷键；修改后会随其他快捷键一起持久化，注册失败时恢复原设置。
