猛人桌面助手v18.22正式版 使用说明

一、普通截图（F1）

按 F1 后全部显示器同时进入截图状态。
可以把鼠标移到任意屏幕，单击自动识别的窗口，或按住左键自由拖出截图区域。
支持跨屏自由拖框，以及在截图编辑状态下再次按 F1 进行嵌套截图。
在 4K 或不同缩放比例的多屏电脑上，每块屏幕会使用独立遮罩；四屏仍会同时进入截图状态，无需修改 Windows 缩放比例。
按下 F1 的瞬间，软件需要读取全部显示器并生成选区预览，CPU 短暂升高属于正常现象；
进入选区界面后占用应迅速回落，不应持续保持高占用。

截图后支持镜像、绘图、文字、字号、粗细、颜色、橡皮擦、清除、撤销和恢复、
实心矩形覆盖、贴图、复制、保存和翻译。
截图编辑工具栏左侧有“移动”按钮。按住“移动”并拖动，可把工具栏移到不遮挡内容的位置。
右键撤销上一笔或上一步编辑；Ctrl+右键恢复刚撤销的内容。
也可以使用 Ctrl+Z 撤销、Ctrl+Y 恢复。

文字的用法（截图和教鞭相同）：
- 选择“文字”后单击画面，会在单击处直接出现输入框，输入的文字和光标按最终颜色、字号实时显示；按 Enter 或单击别处完成，按 Esc 取消。
- 文字完成后，按住文字拖动即可移动到任意位置，用来校准第一次落点。
- 单击已有文字（不拖动）可重新修改内容；把内容全部删掉即删除该文字，也可以选中后按 Delete 删除。
- 单击选中文字后（出现蓝色虚线框），再选择颜色或字号，会直接改变这段文字的颜色和大小。颜色窗口总是显示在截图和教鞭画面的最上层，出现在工具栏旁边，可按住标题栏拖动。
- 移动、修改、改色都可以用 Ctrl+Z 撤销；橡皮擦碰到文字会擦掉整段文字。

二、纵向长截图（F2）

按 F2 后框选需要滚动的内容区域，单击选区开始。软件默认采用分段自动滚动：
每次只滚动一段，等待画面稳定后再拼接，并自动调整滚动幅度以保留足够重叠。滚动幅度会按 Windows“鼠标滚轮一次滚动的行数”自动换算，不同电脑的每段位移基本一致。连续两帧稳定确认、重叠检查和多位置五次到底确认持续生效。
检测到画面未移动时，软件会改用小步滚动，依次在选区左、右及不同高度的安全位置探测。累计五次都没有整体位移且已经拼接过新内容时，才会判断到达页面底部并自动完成。
进行中会显示“自动/手动、暂停、完成（F2）、取消”控制条；再次按 F2 或点击“完成”可在当前位置生成图片，Esc 取消。
点击“自动模式”可切换到手动模式；手动滚轮后稍作停顿，软件会利用滚动过程中的过渡画面恢复重叠。
如果自动滚轮不被目标程序接受，会自动切换手动模式；如果拼接暂时失去重叠，会进入仍在采集的手动恢复模式，请向上滚回有重叠的位置，再小幅向下滚动。手动模式不会根据短暂停顿猜测页面底部，以免提前结束；到目标位置后请按 F2 或点击“完成（F2）”。页面持续大范围变化时软件仍会暂停并提示处理，不会静默漏掉内容或勉强拼接不稳定画面。
不建议按下鼠标中键连续自动滚动，因为持续运动的过渡画面会降低拼接稳定性。

长截图完成后点击“裁剪”，软件会默认保留完整长图。
可以滚动到图片底部，把蓝色下边界向上拖动，只删除末尾不需要的部分；
调整完成后再次点击“完成”。裁剪按原始图片像素执行，不降低清晰度，
按 Ctrl+Z 可以撤销。

三、教鞭模式（F4）

按 F4 进入后，支持画笔、直线、箭头、方框、实心矩形、圆形、文字、
橡皮擦、颜色和粗细。绘图工具使用蓝白画笔光标，笔尖朝向左上角，
笔尖位置就是实际落笔位置；文字工具仍使用竖线输入光标，可以连续输入多段文字，
每段文字都能拖动、重新修改和改颜色（用法见“一、普通截图”中的文字说明）。

教鞭工具栏提供“隐藏/显示”“撤销”“恢复”和“清除”按钮。
工具栏使用黑色底板单排布局，顺序为“移动、隐藏、鼠标、画笔、箭头、直线、方框、
实心、圆形、文字、颜色、粗细、橡皮、撤销、恢复、清除、退出”。绘图区的蓝白画笔光标为原尺寸的 3/4。
点击“隐藏”会保留全部笔迹、暂时隐藏画面并自动切换到鼠标模式，可操作下方软件；
再次点击“显示”会恢复原有笔迹，并回到隐藏前的绘图工具继续绘制。
在绘图区点击右键，可撤销上一笔；按住 Ctrl 再点击右键，可恢复刚撤销的一笔。
也可以使用 Ctrl+Z 撤销、Ctrl+Y 恢复。

单独切换到“鼠标”时会保留笔迹显示；需要保存教鞭画面时按 F1 截图。
再次按 F4 或点击“退出”关闭。
按住最左侧“移动”按钮，可以把整条工具栏拖离腾讯会议等软件的控制区。
按“鼠标/画笔切换”快捷键时，工具栏会立即在“鼠标”和当前绘图工具之间同步显示；
Windows 下采用轻量的原生点击穿透切换，减少全屏窗口状态调整带来的等待。

四、F3 桌面工具

按 F3 或点击主窗口、托盘菜单中的“桌面提醒”，会出现紧凑的桌面工具栏。
工具栏的按钮尺寸与 F1 截图工具栏一致（48×32 像素），F1 与 F3 的按钮文字统一使用 13 像素字体，顺序为：
“移动、桌面/置顶、文字贴图、图片贴图、闹钟、计时器、倒计时、睡眠、计算器、退出”。
五种挂件功能可以分别创建多个桌面项目，互不影响。
点击“退出”、再次按 F3 或按 Esc 可关闭工具栏，已创建的桌面挂件不受影响。
工具栏左侧提供“移动”手柄；按住“移动”并拖动，可将整条工具栏放到屏幕任意位置。
“桌面/置顶”按钮文字表示当前模式：“桌面”让全部挂件保持在普通窗口下方；“置顶”让全部挂件持续显示在最顶层。
切换会立即作用于已经创建的全部挂件，并自动保存，软件重启后继续使用上次选择；首次使用默认为“桌面”。
点击“睡眠”后会先显示确认框；选择“是”才会让 Windows 进入普通睡眠。点击“计算器”可直接打开 Windows 计算器。
这两个工具还提供独立全局快捷键：默认按 Shift+Q 可打开计算器，再按一次关闭；默认按 Shift+F12 会直接让电脑进入普通睡眠，不显示确认框。
关闭后再次调出时，会保留本次软件运行期间最后一次拖动的位置。

文字贴图支持输入文字、选择颜色和完成状态；图片贴图用于单独加载图片。
文字和图片贴图未被选中时不显示虚线方框和缩放手柄，保持桌面画面干净。
单击贴图后才显示方框及右下角手柄；点击挂件空白处或其他软件后会取消选中并隐藏方框。
选中后拖动手柄即可自由放大或缩小：
调整文字框高度会同步改变实际字体大小，调整宽度可改变文字换行范围；外框会按照实际文字行数自动收紧，
不会把用于控制字号的高度全部显示成上下空白。
图片和外框会始终保持原图比例，不再出现图片已经适配宽度、外框上下仍有大块空白的情况。
图片最大尺寸按当前所在显示器计算，可放大到接近铺满单个桌面的可用区域；多屏环境下不会被放大到跨越全部屏幕。
可以选择是否显示完成状态。开启后，“未完成”使用橙红色醒目标识，“已完成”使用绿色勾选标识。

在默认“桌面”模式下，全部文字、图片、闹钟、计时器和倒计时挂件保持在 Windows 桌面上方、普通窗口下方。
打开或切换到其他软件时，其他窗口只会遮住与挂件重叠的区域；未被窗口遮挡的挂件部分仍然可见，
因此不会因为点击其他软件而整体消失。挂件平时只用于显示，只有按住挂件左键拖动时才会移动；
文字和图片可双击或右键选择“修改提醒”，右键还可以切换完成状态或删除。
内容、样式、位置和计时状态都会自动保存，软件重新启动后会恢复。

闹钟支持指定具体日期和时间。计时器是从零开始向上计时的秒表，窗口直接提供“开始、暂停/继续、
重置、取消”按钮；重置后回到 00:00:00 并等待再次开始。
倒计时支持分别设置小时、分钟和秒，挂件会实时显示剩余时间；它提供与计时器相同的“开始、
暂停/继续、重置、取消”按钮，并额外提供“修改”按钮。
闹钟或倒计时到点后，无论当前选择“桌面”还是“置顶”，都会另行弹出一个位于最顶层的提醒窗口并持续响铃；
点击提醒窗口中的“停止响铃并关闭”即可结束提示。
开源版本默认使用程序自动生成的内置提醒音，也可选择本机 WAV、MP3、M4A、AAC、FLAC 或 OGG 文件。
公开源码不包含第三方歌曲；已为某个闹钟或倒计时选择的自定义音乐保持不变。
选择的图片和音乐会复制到软件配置目录，原文件之后移动或删除也不会影响已经保存的挂件。

F3 默认用于桌面工具，可以在“修改快捷键”中改成其他组合。

五、后台运行

启动后软件驻留在系统托盘。关闭主窗口不会退出软件。
需要完全退出时，请右键托盘图标并选择“退出”。
测试新版本前，应先退出托盘中的旧版本，不能同时运行两个版本。

六、快捷键

主窗口或托盘菜单中点击“修改快捷键”，可以修改 F1、F2、F3、F4、计算器、睡眠以及教鞭工具快捷键。
默认快捷键为：F1 普通截图、F2 纵向长截图、F3 桌面工具、F4 教鞭、Shift+Q 打开/关闭计算器、Shift+F12 直接睡眠。
计算器和睡眠快捷键可以修改，也可以清空后停用。Shift+Q 第一次按下打开计算器，再按一次关闭；Shift+F12 属于立即执行操作，不会弹出确认框，请避免设置成容易误触的组合。
修改快捷键窗口打开期间，全局快捷键会暂时停用，
因此输入 F1—F4 不会误触发截图、桌面工具或教鞭。按 Esc 可安全取消设置，不会将 Esc 记录为快捷键。
若快捷键与其他软件冲突，软件会弹窗提醒并拒绝保存。
教鞭中的 Ctrl+Z、Ctrl+Y、右键撤销和 Ctrl+右键恢复无需另外设置。
自定义的鼠标/画笔切换、画笔、直线、方框、圆形、箭头、文字、橡皮、清除、撤销和恢复快捷键，
只在教鞭模式开启期间注册和生效；退出教鞭后会立即释放，不会影响其他软件。

七、贴图

截图后点击“贴图”。鼠标拖动可移动；每次按 1 旋转 90°；
Ctrl + 鼠标中键滚动可调整透明度；双击贴图可关闭，与按 Esc 的作用相同。

八、翻译

翻译功能支持有道、DeepL、OpenAI、Google Cloud 和 Microsoft Translator。
请在“翻译 API 设置”中选择服务并填写自己的密钥。
未填写所选服务的密钥时，点击“翻译”会显示清晰可见的设置提示。
